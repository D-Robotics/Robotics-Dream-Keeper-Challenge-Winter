# Stage 2 — Build Challenge

| Field | Value |
|---|---|
| **Window** | November 11–26, 2026 |
| **Duration** | 15 days |
| **Slogan** | Design Your Own Intelligent Robot |
| **Hardware baseline** | RDK X5 plus the planned sensors and actuators for Stage 3 |

## Core Objective

Move from running demos to designing an intelligent robot system with a clear problem, architecture, compute plan, and executable engineering roadmap.

## Challenge 1 — Concept and Application Design

Document:

- Operating scenario and constraints.
- Intended user and interaction model.
- Core perception, decision, and actuation capabilities.
- Innovation compared with a stock demo.
- Measurable success targets, such as latency, FPS, accuracy, or task success rate.

## Challenge 2 — AI System Architecture

Deliver:

1. A data-flow diagram from sensors through AI and decision logic to actuators.
2. Module responsibilities, inputs, outputs, and failure modes.
3. Compute allocation across BPU, CPU, and any justified off-board service.
4. A ROS 2 node graph with topics, services or actions, message types, and expected rates.

Diagrams may use Mermaid in Markdown. If a rendered image is used, keep it under the participant's own repository and ensure text is legible.

## Challenge 3 — Engineering Plan

Provide all of the following:

- BOM with quantity, supplier or SKU, voltage/interface notes, and optional estimated cost.
- Timeline or roadmap through the final demo.
- Top five risks with mitigation, trigger, and fallback.
- Planned GitHub structure such as `src/`, `launch/`, `models/`, `config/`, `docs/`, and `tests/`.

## Required Deliverables

| # | Item | Requirement |
|---|---|---|
| 1 | Project roadmap | Public GitHub Project or equivalent `ROADMAP.md` |
| 2 | Proposal | Markdown file covering concept, user, measurable goals, and innovation |
| 3 | Architecture | System diagram, module table, compute allocation, and ROS 2 graph |
| 4 | Engineering plan | BOM, schedule, risks, and repository structure |
| 5 | Community post | Public summary and permalink |
| 6 | Showcase PR | Updated showcase file under `projects/` |

## Completion Reward

- RDK Builder title and Discord identity.
- Stage 3 access.
- One hour of 1-on-1 technical support.
- Show & Tell consideration for strong proposals.
