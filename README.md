## Overview

The **Robotics Dream Keeper Challenge** is a **staged, hands-on robotics program** built around real hardware and production-style delivery. Participants progress from first boot on **D-Robotics RDK X5** to a **complete, demo-ready AI / robotics project** with ROS 2 integration, accelerated inference, and community visibility.

Each stage has a suggested milestone window, but submissions can **roll flexibly** across the full program period. **Complete all 3 stages by December 15, 2026** to be considered as having finished the full program.

**Why join:** You gain structured milestones, **embedded Online Bootcamp** sessions, **weekly office hours / Q&A**, and direct **RDK technical support** from the ecosystem team. You improve system design and on-device AI skills, earn **titles, badges, and awards**, and connect with the global **RDK developer community**.

## Registration

Complete all onboarding steps to unlock Stage 1 and program support:

1. **Submit the application form:** https://forms.gle/ojG5pRmWXMsM27Vb9
2. **Join the official Discord challenge channel:** https://discord.gg/ydVxBpz3vP
3. **Post a short self-introduction** in your personal Discord forum thread.
4. **Install and activate RDK Studio:** https://developer.d-robotics.cc/en/rdkstudio

Eligible registered participants enter a draw for one of **three RDK stereo cameras**. Final eligibility and shipping terms will be announced by the organizers.

## How to Participate

1. Create your own public GitHub repository for code, logs, designs, and experiments.
2. Complete the challenges for the current stage and collect the required evidence.
3. Update your personal Discord challenge thread with links to each stage deliverable.
4. Submit one project showcase document to this official repository by opening a Pull Request that adds a file under [`projects/`](./projects/).

- [Project submission template](./projects/README.md)
- [Step-by-step Pull Request guide](./docs/github-pr-guide.md)
- [RDK X5 challenge guide](./docs/rdk-guide.md)
- [Frequently asked questions](./docs/faq.md)

> Participant source code stays in the participant's own repository. This repository accepts project showcase documents, not full project codebases.
